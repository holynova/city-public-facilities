ABOUT / 01

近邻：城市公共设施近邻检索

输入地址或使用当前位置，近邻会在已覆盖城市的设施目录中按大组比较直线距离，并列出每个细分类别最近的三个地点。本页说明数据如何形成、多久更新，以及结果适合和不适合做什么。

FEATURES / 03

可以做什么

  1. 01

    按地址查找

    通过高德地图解析地址坐标，再计算各大组下细分类别的最近结果。

  2. 02

    使用当前位置

    允许定位后自动选择附近已支持的城市，不需要先手动切换。

  3. 03

    按大组快速筛选

    教育、交通、文化艺术、医疗健康、环境休闲、商业购物、公共服务和城市地标可整组筛选。

  4. 04

    分享查询结果

    生成带项目链接、二维码和全部分组结果的紧凑长图，方便保存或转发。

SCOPE / 04

数据方法与使用边界

数据从哪里来

项目以公开目录和高德地图地点数据整理城市设施清单；三河（燕郊）目录基于 OpenStreetMap contributors 的公开地图数据快照整理，并转换为 GCJ-02 坐标。具体分类仍应以主管部门或场所公告为准。

距离怎么算

查询地址先由高德地图解析为坐标，再计算查询点与已覆盖城市目录中设施之间的球面直线距离。结果不包含道路、入口、交通方式或实时路况。

数据多久更新

网站展示的是按需人工更新并发布的静态数据快照，不是实时设施数据库。页面加载时读取当前发布版本，不代表场所此刻仍开放。

结果如何核验

医院等级、学校属性、开放时间、服务范围和场所状态等关键信息，应在出行或决策前向主管部门、运营方或场所官方渠道复核。

已知边界：地点坐标采用 GCJ-02；距离为直线距离；每个细分类别默认返回最近三处；医院等级候选和高校分类不能替代主管部门认定。项目不提供路线规划、实时营业状态或官方资格证明。

FAQ / 05

常见问题

近邻目前支持哪些城市？

当前发布快照覆盖上海、北京、三河（燕郊）、杭州、广州、深圳、苏州、合肥、南京、成都、重庆、武汉、西安、芜湖和珠海，共 15 个城市。

“最近”是否等于步行或驾车距离最短？

不是。近邻按 GCJ-02 坐标计算直线距离，不考虑道路、出入口、交通方式和实时路况。

查询结果是实时数据吗？

不是。设施清单是按需人工更新的静态快照；地址解析在查询时进行，但设施名称、分类与状态可能发生变化。

医院等级和学校属性可以直接作为官方结论吗？

不可以。相关分类用于查找候选地点，不能替代卫生健康、教育等主管部门或场所官方发布的信息。

如何报告错误或补充地点？

可前往项目的 GitHub 仓库提交 Issue，并提供城市、地点名称、可核验来源和需要修正的字段。
